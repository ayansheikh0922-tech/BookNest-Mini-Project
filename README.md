# BookNest-Mini-Project
About the Project
BookNest is an online book library website developed using HTML, CSS and Bootstrap.

Technologies Used
- HTML
- CSS
- Bootstrap 5

Features
- User-friendly interface
- Book collection display
- Navigation bar
- Responsive design
